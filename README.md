## Overview  
This repository contains the code and supporting files for “Lab 2” of a secure communications and cryptography challenge course. The objective of this lab is to apply cryptographic concepts (e.g., encryption/decryption, key management, secure channels) by solving a practical problem coded in Python.

---

## Challenge Description  
In this lab you will be given a scenario where secure messages are exchanged (or intercepted) and you must apply cryptographic techniques/tools to decipher the content, validate integrity, or construct secure communications.  
This implementation (in `challengelab2.py`) performs the essential functions required for the challenge. You’ll likely need to examine the logic, inspect the ciphertext, keys or communication channel, and implement (or break) cryptography accordingly.
